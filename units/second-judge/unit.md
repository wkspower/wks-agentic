# Second judge

Parent: [root](../../root.md). Governed by [`principles.md`](../../principles.md).

## The six declarations

1. **Purpose** — The judge is itself judged: a change to the unit [`judge`](../judge/unit.md) stands only when allowed and measured better, decided by something the judge does not contain and cannot alter.
2. **Interface** — Offers `decide <base> <head> judge --tools <tree> --work <dir>`, with the same answer as the judge's; *build* and *verdict* through [`tree`](../cycle/unit.md). Receives the same as the judge.
3. **Rules** — The principles; it decides by rules 1 and 3 of [the judge's document](../judge/unit.md), and refuses every unit but `judge`.
4. **Budget** — Attempts: 3 per change (root). Effects without undo: zero. Attention: one item open in the root's queue (`units/queue.md`). Time: a decision within 30 minutes. Context: this document within 80 lines. Cost: nothing outside the repository.
5. **Measure** — [`measures/second-judge/check`](../../measures/second-judge/check), written by the root before this unit. Number: cases right.
6. **Judge** — [`judge`](../judge/unit.md).

## The principles here

| Principle | At the second judge |
|---|---|
| 1 Boundary | It sees the judge only through the judge's measure and the enforcer's answer. |
| 2 Single source | It cites the judge's rule of decision and adds none. It shares no code with the judge, so one change cannot alter both. |
| 3 External enforcement | The cycle runs the second judge of the last recorded state; the measure used is the one of `<base>`. |
| 4 Rehearsal before effect | It runs only inside the cycle's rehearsal place and has no effect of its own. |
| 5 Return | It keeps no state; the cycle returns a rejected change. |
| 6 Selection | A change to it stands only by the judge. The two judge each other, so neither judges itself and the chain needs no person below the root. |
| 7 Escalation | It asks nothing: a change to the judge it cannot measure does not stand. Limit: as for the judge, independence is by what can be altered, not by who created it. |
