# L0013 — Done means every case in force passes, the agent drove the product by script as a person would and read what came out, and what was not verified is said; none of that is the person using it

## Reason
Cases check what someone thought to check. Four problems on 2026-11-18 were
found only by using the program. So before a run is called done the product
is used, not only tested: for web pages, a script drives a real browser
through what a person would do, at a wide and a narrow width, and the agent
reads the screenshots. The report of a run names what was looked at this way
and what was not verified, so the person does not take silence for a pass.

That is all "used by hand" has ever been here: a script, and the agent
reading its own screenshots. It found a defect in each of runs 001, 002 and
004, so it is worth doing. It is still the builder looking at its own work
(L0003), and it is a different thing from the person sitting at the app.
The report says "driven by script and read by the agent", not "used by hand".

The person's own use of the pet shop has not happened yet (2026-11-19).
When it does, what it finds is evidence from outside and becomes lessons.

## Source
The person, run 001, 2026-11-19 (answer 14), under the words "used by hand".
The run records of 001, 002 and 004 each say that nobody sat at it. Reworded
on the person's decision of 2026-11-19 (run 005): the lesson says what
really happens, and the person's use is kept apart from it.

## What would be a regression
A run reported as done with no account of what the script did and what the
agent saw, or with no list of what was not verified; or a report that calls
the agent's own look "use by hand" or lets it stand for the person's.
