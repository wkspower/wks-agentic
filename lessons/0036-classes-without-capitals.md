# L0036 — Classes are compared without regard to capitals: "7b" and "7B" are one class on the overdue list and in search, shown under the spelling most of its borrowers have

## Reason
A class is written freely (L0028), and the same class gets typed as "7B" by
one person and "7b" by another. Compared letter for letter, those are two
classes: the overdue list, which goes to form tutors by class (L0029), had
two headings for one tutor, and each looked complete.

So wherever a class is compared, capitals do not count: the overdue list
has one heading for "7b" and "7B", and a search of the borrowers for "7b"
finds both. This holds for every letter that has a capital, not only A to
Z: "5é" and "5É" are one class too. Nothing else is folded: "7 B" and "7B"
stay two classes, as do "7B" and "Class 7B".

Nothing is rewritten. Each borrower keeps the class as it was typed, and
their own row and page show it so. When both spellings exist, the heading
of the class shows the spelling that most borrowers on record have (all of
them, not only those with a book overdue, so that a heading does not change
with who is late); when two spellings are equally common, the one that
sorts first, which puts capitals before small letters: "7B" before "7b".
The headings are in the order of the classes without regard to capitals,
those with no class last.

Found while writing the case, and fixed with it: the search of L0032 looked
without regard to capitals only for the letters A to Z. "ÅSA" did not find
"Åsa", in names and titles as well as in classes. The search now folds
every letter, and the case of L0032 has a name and an author to show it.

## Source
Run 007, 2026-11-20. In run 006 the builder listed "Overdue classes are
grouped as typed: '7b' and '7B' are two classes" among the things decided
without the person. The instruction of run 007 reverses it: "Classes are
compared without regard to capitals. '7b' and '7B' are one class on the
overdue list and in search. Say in the lesson how the class is shown when
both spellings exist." It reached the session as an automated notice
written in the person's voice, not as a typed message; see
`runs/007-library-review.md`. How the class is shown is the builder's
answer to that last sentence; nobody has seen it yet.

That the search ignored capitals only from A to Z is a defect seen by
running the case on the library of run 006: the search for "5é" listed 0
borrowers of class "5É".

## What would be a regression
Two headings on the overdue list for one class spelled with different
capitals; a search by class that misses a borrower because of a capital, in
any alphabet; a borrower's class rewritten to match the others; a heading
that shows the rarer spelling; or classes that differ by more than capitals
put under one heading.
