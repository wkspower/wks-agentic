# L0003 — Agreement between agents of the same model is not evidence that something is right

## Reason
Agents of one model share training and blind spots. Giving them separate
context isolates them; it does not make them independent. Evidence is a
check that runs, real data, or the person.

## Source
The wizardly-cerf run, 2026-11-18. Measures, audits and both blind builds
agreed on every unit, and the record reported 0 wrong passes. Using the
program by hand then found four problems none of them looked for: cross-site
posts accepted, the command line and the web app overwriting each other's
state, no upper bound on prices, and a customer preselected on the sale form.
The same effect is known from N-version programming (Knight and Leveson, 1986).

## What would be a regression
A result reported as verified when the only verifier was another agent's
opinion.
