# Queue of the root

The one queue of principle 7 for [`root.md`](root.md): everything the root
puts before the person, and nothing else. Each item is complete enough to
decide without reading the work. An answer given in the channel counts only
once it is written here; it is then absorbed (turned into a rule or a case of
a measure) before the work proceeds, and never asked again.

Attention is counted from this file by [`measures/root/check`](measures/root/check):
one per item, plus the days between *asked* and *answered*. The line under
each heading is read by that check; "after result N" is the last line of
[`ledger.jsonl`](ledger.jsonl) that existed when the item was asked. The
options each item offered are in this file's history.
