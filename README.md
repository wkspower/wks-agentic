# Autonomy tree

Principles and root of a tree for autonomous development that respects the
need for, and the limits of, human participation.

## Documents

- [`principles.md`](principles.md) — what governs every unit at every level.
- [`root.md`](root.md) — the root unit of this tree.

Everything else in this repository is created by the tree itself, under those
two documents. This README states no rule; where it and the documents differ,
the documents prevail.

## Status

Starting point of a continuous cycle. Nothing has been built yet.
